Credit Card Fraud Detection

This demo uses a Random Forest model to predict whether a credit card transaction is fraudulent.

Dataset: Credit Card Fraud Detection dataset from Kaggle. It contains 284,807 transactions, including 492 fraudulent transactions.

Source: Kaggle – Credit Card Fraud Detection

Example Transaction

The original dataset was split into 80% training data and 20% test data. The example below is a real fraudulent transaction from the test set that was not used to train the model.

Each transaction contains 30 input features: Time, Amount, and V1–V28. V1–V28 are anonymized features transformed using PCA.
